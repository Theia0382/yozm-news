# ADR-0195: 스토리라인 잇기의 띠와 확률 기준의 처음 값은 시뮬레이터 격자로 좁히고 평가 인스턴스와 운영자 표본 검수로 정밀도를 앞세워 정한다

- 상태: 승인
- 날짜: 2026-11-17
- 근거: [이슈 #169](https://github.com/Theia0382/yozm-news/issues/169) — 잇기 시뮬레이터로 띠 · 확률 기준 · 서술 사건 수를 격자로 견주고, 평가 인스턴스에서 후보를 다시 이어 재고, 운영자가 후보 사이를 가르는 소속과 스토리라인 표본을 판정함
- 관련: [ADR-0194](0194-storyline-linking-asks-jev-only-for-band-candidates-and-reuses-recorded-probabilities-until-either-side-doubles.md)(띠 판정), [ADR-0173](0173-storyline-linking-threshold-default-chosen-for-precision-on-an-evaluation-set-grid-and-operator-sample-review.md)(결정 "기준 점수의 기본값은 0.86 이다" — 부분 대체, 격자와 운영자 표본 검수 · 결과의 분야 모음 — 보충), [ADR-0096](0096-instance-bound-evaluation-data-kept-out-of-the-public-repository-and-defaults-cite-only-the-evaluation-set.md)(근거 수치를 공개 문서에 적지 않는다)

## 맥락

- 띠 판정([ADR-0194](0194-storyline-linking-asks-jev-only-for-band-candidates-and-reuses-recorded-probabilities-until-either-side-doubles.md))의 기준은 아래 기준 · 위 기준 · 확률 기준이다. 띠를 넓힐수록 묻는 후보 · 비용이 늘고, 확률 기준이 정밀도와 재현율을 가른다.
- 격자의 점마다 평가 인스턴스로 다시 이으면 Jev 비용과 시간이 든다. 판정은 앞 판정이 스토리라인을 바꿔 뒤 질문을 바꾸므로 답을 미리 모을 수 없다.
- 평가 세트에서는 이웃한 값 사이의 차이가 씨앗 단위로 다시 뽑은 구간 안이다. 분야 모음을 거르는 이득은 평가 세트의 정밀도에 작게만 드러난다.

## 결정

- **기본값은 평가 세트와 운영자 표본 검수로 정했다.** 값의 정본은 설정 클래스와 [storyline Spec §7](../specs/storyline.md#7-설정)이다. 서술 사건 수 · 한 번에 묻는 후보 수 · 시간 창은 그대로 둔다.
- **값은 셋을 차례로 거쳐 정한다.**
  - 운영 판정을 옮긴 시뮬레이터로 격자를 좁힌다. 띠 없는 지금 기준을 시뮬레이터와 평가 인스턴스에서 함께 돌려 같은 지표가 나오는지 먼저 본다. 답은 질문마다 캐시해 설정 사이에 나누고, 새로 묻는 양은 도구가 한도로 막는다.
  - 고른 후보를 평가 인스턴스에서 운영 코드로 다시 이어 잰다. 시뮬레이터의 예측과 어긋남이 크면 이웃 값을 더 잰다.
  - 운영자가 후보 사이를 가르는 표본을 판정한다 — 띠가 걸러낸 옛 소속, 띠 안에서 판정으로 붙은 소속, 낮은 확률 기준만 붙이는 소속, 큰 스토리라인, 무작위 스토리라인. 표본은 씨앗을 밝혀 뽑고, 판정 기준으로 미리 판정해 두면 운영자가 고친다.
- **같은 품질로 보이는 후보 가운데서는 정밀도를 앞세운다.** 정밀도를 거의 잃지 않고 재현율을 되찾으며, 띠가 걸러낸 옛 소속이 대부분 분야 모음이고 판정으로 붙인 소속이 대부분 맞는 값을 고른다. 확률 기준을 낮춰 더 붙이는 소속이 분야 · 인물 모음으로 흐름을 넓히면 고르지 않는다.
- **값을 고르는 동안에는 실측 인스턴스를 바꾸지 않는다.** 표본은 평가 인스턴스의 결과로 만든다. 실측 인스턴스는 정한 값을 담은 판으로 한 번 올린다.
- 근거 수치는 공개 문서에 적지 않는다([ADR-0096](0096-instance-bound-evaluation-data-kept-out-of-the-public-repository-and-defaults-cite-only-the-evaluation-set.md)).

## 결과

- 기본값이 띠를 가지므로 새 인스턴스 · 기준을 덮어쓰지 않은 인스턴스의 잇기에 Jev 비용이 든다.
- 표본은 고정 덤프의 열흘 남짓이다. 몇 주에 걸친 전개, 실측 인스턴스의 하루 비용과 잇기 처리량은 정한 값으로 실측 인스턴스를 올린 뒤 잰다.
- 기사 한 건짜리 사건은 따로 다루지 않는다 — 표본에서 따로 다룰 근거가 나오지 않았다.
- 기본값은 측정한 소스 구성 · 기본 임베딩 모델 · 문구 판에 맞춘 값이다. 다른 구성이나 문구 판에서는 운영자가 표본을 검수해 맞춘다.
- 바꾼 기준은 그 뒤 판정에만 쓴다. 지난 소속을 새 기준으로 다시 잇는 기능은 없다 — 운영자가 채우기로 다시 잇는다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 평가 인스턴스로만 격자를 잰다 | 격자의 점마다 다시 잇는 시간과 Jev 비용이 든다 |
| 실측 인스턴스에 후보를 차례로 걸어 표본을 검수한다 | 정해지지 않은 값으로 운영 데이터를 갈아엎고, 리뷰 전 코드를 실측 인스턴스에 올린다. 평가 인스턴스 결과로 같은 표본을 비용 없이 만들 수 있다 |
| 확률 기준을 낮춰 재현율을 더 얻는다 | 더 붙는 소속에 흐름 밖의 소속이 많았다 |
| 위 기준을 올려 띠 위쪽을 더 판정에 맡긴다 | 같은 확률 기준에서 평가 세트 품질이 내려갔다 — 그 점수대의 소속은 대부분 맞았다 |
| 아래 기준을 더 내린다 | 판정이 느슨하면 큰 덩어리가 생기고 비용이 크게 는다 |
| 평가 세트의 F1 이 가장 높은 값을 고른다 | 이웃한 값 사이의 차이가 구간 안이고, 분야 모음 거르기의 이득은 평가 세트에 작게만 드러난다 |

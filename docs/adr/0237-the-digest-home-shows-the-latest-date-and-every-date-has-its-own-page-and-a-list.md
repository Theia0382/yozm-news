# ADR-0237: 다이제스트 홈은 가장 늦은 날짜의 다이제스트를 보이고, 날짜마다 화면과 날짜 목록을 둔다

- 상태: 승인
- 날짜: 2026-11-18
- 근거: [이슈 #179](https://github.com/Theia0382/yozm-news/issues/179) — 수용 기준 "오늘 · 날짜별 다이제스트 … 지난 날짜 목록", "홈 진입을 다이제스트 화면으로", 리드와 정함(홈은 가장 늦은 날짜 · 홈 · 날짜 화면 · 목록 화면). 구현 커밋 `39e730a`(공개 조회) · `cbe227c`(화면용 API) · `7dbf1de`(화면)
- 관련: [ADR-0231](0231-manual-generation-remakes-todays-digest-with-its-period-or-makes-a-new-one-and-counts-manual-rows-of-the-users-day.md)(관련 — 수동 생성 대상이 오늘이라 다시 만들기 버튼은 홈에만 둔다), [ADR-0192](0192-reader-screens-are-composed-by-the-reader-module-over-module-public-queries.md)(관련 — 화면용 API 는 `reader`)

## 맥락

- 일정 다이제스트는 사용자가 정한 생성 시각(기본 07:00)이 지난 뒤 만들어진다 — 그날 0시부터 생성 시각까지, 그리고 생성이 끝나기까지는 오늘 날짜의 다이제스트가 없다.
- 시간대를 서쪽으로 바꾸면 사용자 시간대의 오늘보다 늦은 날짜의 다이제스트가 있을 수 있고, 수동 생성은 그 날짜를 다시 만든다.
- 다이제스트는 날짜마다 쌓이는 개인 뉴스 기록이다.

## 결정

- **홈은 가장 늦은 날짜(다이제스트 행이 있는 날짜 — 계기 · 상태 무관)의 다이제스트를 보인다** — 그 날짜가 사용자 시간대의 오늘이 아니면 오늘 다이제스트를 언제 만드는지(관심 설정의 생성 시각) 함께 알린다. 오늘 행이 생기면 그 날짜의 상태(만드는 중 · 실패 · 후보 없음)가 보이고 어제 것은 이전 날짜로 간다.
- **날짜마다 주소가 있는 화면(`/digests/{date}` — 이전 · 다음 날짜)과 날짜 목록 화면(`/digests`)을 둔다** — 실패 알림이 그 날짜로 잇는다.
- **수동 생성 버튼은 홈에만 둔다** — 대상은 언제나 오늘(또는 그보다 늦은 날짜)이다.

## 결과

- 언제 들어와도 읽을 것이 있다. 홈의 제목은 "오늘 다이제스트"이지만 그 아래 날짜를 적어 어제 것임을 밝힌다.
- 수동 생성의 대상과 홈이 같은 날짜를 가리킨다(오늘 이후의 날짜가 있을 때).

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 사용자 시간대의 오늘 날짜만 보인다 | 0시부터 생성 시각까지 홈이 비고, 오늘보다 늦은 날짜가 홈에 보이지 않는다 |
| 홈과 날짜 화면만 두고 이전 · 다음으로만 옮긴다 | 오래된 날짜를 찾으려면 수십 번 넘겨야 한다 |
| 홈 아래에 날짜 목록을 함께 | 홈이 길어지고 홈 질의가 는다 |

# ADR-0189: 끝난 스토리라인의 구독은 그대로 두고, 구독 조회가 지금 상태를 함께 낸다

- 상태: 승인
- 날짜: 2026-11-16
- 근거: [이슈 #184](https://github.com/Theia0382/yozm-news/issues/184) — 구현 커밋 `a7ed33a`
- 관련: [ADR-0107](0107-storyline-state-is-judged-at-query-time-from-the-last-article-and-an-ended-storyline-still-links.md)(전제 — 상태는 조회 때 정하고 끝나도 잇기를 막지 않는다), [ADR-0188](0188-storyline-subscriptions-follow-retired-storylines-by-event-and-before-each-use-and-notices-point-to-the-remaining-event.md)(구독이 바뀌는 다른 계기)

## 맥락

- 스토리라인의 상태(진행 · 잠잠 · 끝남)는 저장하지 않고 조회할 때 마지막 기사 시각으로 정한다. 끝난 스토리라인에 뒤 기사가 있는 사건이 붙으면 다시 진행이 된다.
- 끝남은 일어나는 일이 아니라 조회 때의 판정이라, 그것을 계기로 무언가를 하려면 스토리라인을 훑는 반복 작업이 따로 있어야 한다.

## 결정

- **끝난 스토리라인의 구독을 해제하지 않는다.** 구독 조회는 스토리라인마다 지금 상태를 함께 낸다. 끝난 것을 쓸지 · 어떻게 보일지는 소비자와 화면이 정한다.

## 결과

- 다시 진행된 흐름을 구독이 그대로 따라간다.
- 끝난 구독이 목록에 쌓일 수 있다 — 사용자가 직접 해제하고, 구독 수 상한이 그 크기를 막는다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 끝나면 반복 작업이 자동 해제한다 | 다시 진행된 흐름을 놓치고, 조회 때의 판정을 훑는 작업이 새로 생긴다 |

# ADR-0226: 새로 생긴 관심 · 사라진 관심은 관심 값이 기준값 이상인지를 이웃 기간끼리 견주어 정한다

- 상태: 승인
- 날짜: 2026-11-18
- 근거: [이슈 #189](https://github.com/Theia0382/yozm-news/issues/189) — 산식이 내는 관심 x 의 성질(구독 하나 · 노출과 좋아요의 비율 · 감쇠)을 수치로 견주고 리드와 정함. 구현 커밋 `77bfe43` · `bb602eb`
- 관련: [ADR-0215](0215-interests-are-not-stored-entities-and-are-computed-from-signal-history-at-query-time.md)(결과 "새로 생긴 관심 · 사라진 관심은 계산 결과를 견주는 기준이 하나 더 필요하다 — 히스토리를 만드는 작업이 정한다" — 보충), [ADR-0222](0222-interest-per-subtopic-is-smoothed-reactions-over-exposures-with-a-half-life-and-exposures-are-all-ready-citations.md)(관심 x 의 산식)

## 맥락

- 관심사 히스토리는 기간별 주제 관심도와 새로 생긴 관심 · 사라진 관심을 보인다. 관심 x 는 −1 ~ 1 의 연속 값이라 "생겼다 · 사라졌다"를 정할 기준이 따로 필요하다.
- 산식의 성질(K 3 · γ 1): 구독 하나만이면 x = 1/3, 노출 10 · 좋아요 2 면 0.154, 노출 10 · 좋아요 5 면 0.385, 그 뒤 60일 신호가 없으면 0.227. 구독한 주제에 반응 없이 노출만 쌓이면 x 는 0 쪽으로 간다(구독 + 노출 10 → 0.077).
- 화면은 주제가 많아질 수 있다 — 노출이 하나라도 있으면 x 가 생기고, 반응 없는 노출만 있으면 x 는 0 근처다.

## 결정

- **관심 x 가 기준값 θ 이상인 주제를 그 기간의 "관심 있음"으로 본다.** 앞 기간에 관심 있음이 아니었고 이번 기간에 관심 있음이면 새로 생긴 관심, 반대면 사라진 관심이다. 첫 기간은 그 앞 기간(보이지 않는 견줌용)과 견준다.
- **θ 는 상수 하나이고 처음 값은 0.2 다** — 측정 전 목표다. 노출의 약 1/4 이상에 좋아요를 누르면 관심 있음이 된다.
- **싫어요 쪽(x ≤ −θ)은 관심 있음으로 세지 않는다.**
- 판정과 θ 는 `digest` 의 `domain` 한 곳에 둔다. 화면은 θ 를 모르고 서버가 낸 생김 · 사라짐 · 드러남을 그린다.

## 결과

- 같은 θ 로 화면에 드러낼 주제도 정한다 — 보인 기간 가운데 한 번이라도 |x| ≥ θ 인 주제(관심 쪽 · 싫어요 쪽)를 행으로 보이고 나머지는 접는다.
- 판정이 산식의 뜻(관심 크기)과 같은 축이고, 다이제스트 순위에서 가중치가 오르내리는 것과 어긋나지 않는다. 리포트도 같은 판정을 쓸 수 있다.
- 감쇠로 x 가 θ 아래로 내려가면 사라진 관심이 된다 — "그동안 반응이 없었다"는 뜻이다. 구독 중인 주제도 반응 없이 노출만 쌓이면 사라진 관심이 된다(구독 상태는 기간마다의 구독 변경으로 따로 보인다).
- θ 를 넘나드는 작은 흔들림이 생김 · 사라짐을 번갈아 낼 수 있다. 빈도는 재지 않았다 — 문제가 되면 들어오는 기준과 나가는 기준을 달리 두는 것을 측정 뒤에 더한다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| x 의 부호(x > 0)로 본다 | 노출 하나에 좋아요 하나도 관심이 되고, 감쇠로는 x 가 0 에 다가가기만 해 사라짐이 거의 안 생긴다 |
| 기간마다 관심 상위 N 주제를 관심 있음으로 본다 | 다른 주제가 오르면 내 관심이 그대로여도 사라짐이 된다. 신호가 적은 사용자에게는 0 근처 주제까지 관심으로 보인다 |
| 화면에 x 가 있는 모든 주제를 행으로 보인다 | 0 근처 행이 많아 생김 · 사라짐이 묻힌다 |

# ADR-0001: 뉴스 소스: 네이버 검색 API 대신 운영자 큐레이션 RSS

- 상태: 승인
- 날짜: 2026-10-25

## 맥락

기획 초안은 초기 뉴스 소스로 네이버 뉴스 검색 API를 정했다. 조사해보니 네이버가 검색 API 약관을 개정했다. 보도 기준 시행일은 2026년 9월 7일이고, 출처에 따라 9/20, 10/7로도 적혀 있다.

- 사용 목적: 네이버 검색 결과를 가공하지 않고 그대로 보여주는 용도로 한정
- 금지: 검색 결과 데이터를 AI에 입력하거나 학습·개선·평가·노출에 활용, 복사·저장·캐싱, 제3자 제공, 수익화
- 신규 이용 신청 중단(2026년 7월 30일 무렵), 기존 이용자 유예 2027년 6월 30일까지

이 서비스는 기사 데이터를 Jev와 LLM에 입력하고 저장해야 하므로 개정 약관과 정면으로 충돌한다. 공식 공지 원문은 직접 확인하지 못했다. 다만 여러 언론 보도와 개발자 기록이 같은 방향을 가리킨다.

## 결정

- 네이버 검색 API를 쓰지 않는다.
- v1 뉴스 소스는 **운영자가 검토·등록한 언론사 공식 RSS 피드**로 한다.
- 소스마다 이용조건을 검토하고 그 날짜를 기록한다. 검토하지 않은 소스는 활성화하지 않는다.
- 공급원은 `ArticleSource` 인터페이스 뒤에 두는 원칙을 유지한다. 초안의 결정이므로 RSS 외 공급원(유료 뉴스 API 등)을 나중에 추가할 수 있다.

## 결과

- 키워드 검색이 아니라 피드 단위로 전체 기사를 받는다. 관심 분야 필터링은 서비스가 맡아야 한다 → [ADR-0002](0002-shared-evaluation-with-jev.md)의 공유 평가가 이 역할을 한다.
- RSS는 대부분 본문을 주지 않는다. 0자에서 500자 정도의 요약문만 준다. v1은 요약문만으로 평가하고 다이제스트를 만든다 ([조사 자료](../research/2026-10-rss-survey.md)).
- 피드 품질이 제각각(비표준 날짜, 깨진 XML, 방치된 피드)이므로 정규화와 피드 상태 관리가 필요하다.
- 피드 목록 관리가 운영 업무가 된다.

## 검토한 대안

| 대안 | 기각/보류 이유 |
|---|---|
| 네이버 검색 API | 개정 약관 위반. 신규 신청도 불가 |
| 사용자가 RSS를 직접 등록 | Jev 비용이 운영자 부담이라 사용자가 피드를 늘리면 운영자 비용이 늘어난다. 악용 위험도 있다. 상한을 두고 이후 검토 |
| 유료 국내 뉴스 API | 라이선스는 명확하지만 고정비가 생긴다. 서비스 검증 후 재검토 |
| 언론사 사이트 직접 크롤링 | 사이트마다 대응이 필요하고 이용조건 위험이 크다 |

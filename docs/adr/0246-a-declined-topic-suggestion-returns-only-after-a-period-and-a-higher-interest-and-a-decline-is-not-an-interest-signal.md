# ADR-0246: 거절한 구독 제안은 기간이 지나고 거절 때보다 관심이 커져야 다시 내고, 거절은 관심 신호가 아니다

- 상태: 승인
- 날짜: 2026-11-19
- 근거: [이슈 #188](https://github.com/Theia0382/yozm-news/issues/188) — 거절 뒤 다시 내는 방식(고정 기간 · 영구 · 기간과 조건)과 거절을 신호로 셀지를 리드와 정함. 구현 커밋 `bdf6bb1` · `ac24312`
- 관련: [ADR-0028](0028-explicit-signals-and-interest-weighted-candidates.md)(보충 — 결정 "관심 신호는 사용자의 명시적 행동만 쓴다"의 목록은 그대로이고 거절은 그 밖이다), [ADR-0245](0245-a-topic-suggestion-is-made-when-the-current-interest-of-an-unsubscribed-subtopic-reaches-its-own-threshold.md)(제안 기준), [ADR-0247](0247-topic-suggestion-declines-are-kept-by-user-with-the-recorded-version-and-digest-answers-the-interest-at-decline-through-an-interface-declared-by-user.md)(거절의 기록)

## 맥락

- 사용자는 제안을 수락하거나 거절한다. 수락은 주제 구독이 되어 제안 조건(구독하지 않음)을 벗어나고, 원인이 사용자인 구독 변경이라 관심 신호가 된다.
- 거절한 제안을 곧바로 다시 내면 귀찮고, 영영 내지 않으면 관심이 바뀐 뒤에도 권하지 않는다.
- 관심은 반감기로 감쇠한다. 같은 행동도 시간이 지나면 값이 달라진다.
- 관심 신호는 좋아요 / 싫어요와 구독 변경(주제 · 스토리라인)뿐이다. "구독(필터)에 넣고 싶지 않다"와 "관심 없다"는 다르다 — 큰 슬롯에서 그 주제 기사를 좋아하며 받되 매일 구독은 원치 않는 사용자가 있다.

## 결정

- **거절한 뒤 기간(처음 값 90일 — 측정 전 목표, 상수 하나) 동안은 그 중분류를 제안하지 않는다.**
- **기간이 지나도 지금 관심이 거절 때 관심보다 엄격히 커야 다시 낸다.** 거절 때 관심은 거절할 때 적어 둔 값이다.
- **거절은 관심 신호가 아니다.** 제안을 다시 내지 않는 데만 쓰고 관심도 · 후보 순위 · 관심사 히스토리에 들지 않는다. 기록은 현재 상태 한 벌이고 이력이 없다.
- 지금 상태는 [digest Spec "구독 제안"](../specs/digest.md#구독-제안) digest-R41 · [user Spec](../specs/user.md#구독-제안-거절) user-R64 다.

## 결과

- 거절 때 관심이 상한 1 이면 다시 나오지 않는다 — "더 커졌을 때만"을 그대로 따른 귀결이다. 사용자는 관심 설정에서 직접 구독할 수 있다.
- 90일이면 반감기 셋이라 거절 때의 신호 무게는 1/8 로 줄어 있다 — 다시 나온다면 새 신호 때문이다.
- 거절은 수락과 달리 관심을 바꾸지 않는다. 관심이 없다는 뜻을 순위에 남기려면 싫어요를 쓴다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 고정 기간만 — 지나고 관심이 기준 이상이면 다시 낸다 | 관심이 그대로여도 기간마다 다시 권한다 |
| 영구 — 한 번 거절하면 다시 내지 않는다 | 관심이 바뀌어도 다시 권하지 않고, 거절을 되돌리는 화면이 따로 필요해진다 |
| 거절을 음의 구독 신호로 센다 | 관심 신호 정의가 바뀐다. "구독은 싫다"를 "관심 없다"로 읽어 순위 · 히스토리까지 내려간다. 추가 전용 이력과 원인이 필요해진다 |

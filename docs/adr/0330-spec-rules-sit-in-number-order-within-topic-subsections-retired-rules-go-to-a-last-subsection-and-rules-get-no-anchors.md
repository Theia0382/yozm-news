# ADR-0330: Spec §5 의 규칙은 주제별 하위 절 안에서 번호순으로 두고, 폐지한 규칙은 끝 절에 모으며, 규칙마다 앵커를 두지 않는다

- 상태: 승인
- 날짜: 2026-11-25
- 근거: [이슈 #281](https://github.com/Theia0382/yozm-news/issues/281) — 규칙 번호가 덧붙인 순서라 하위 절 안에서 번호가 뛰었고(앞 규칙보다 번호가 작은 규칙이 나오는 자리 39곳), evaluation · user 의 §5 는 폐지 규칙 34 ~ 35줄로 시작했다. 다른 문서가 §5 하위 절 앵커로 규칙을 가리키는 링크는 926개다. 구현 커밋 `c804fd3`
- 관련: [ADR-0036](0036-module-spec-holds-internal-structure-and-port-declarations-in-eight-sections.md)(보충 — 폐지한 규칙의 자리)

## 맥락

- 규칙 식별자는 바꿀 수 없어, 번호를 배치에 맞춰 다시 매길 수 없다.
- §5 하위 절 앵커는 다른 문서 · ADR 이 규칙을 가리키는 길이다. 하위 절 이름을 바꾸면 그 링크가 깨진다.
- 문서 검사는 `#` 제목만 앵커로 읽는다. 규칙마다 앵커를 두려면 규칙마다 제목을 달거나 검사기를 넓혀야 한다.
- 규칙을 가리키는 인용은 대부분 링크 없는 글자다. 링크로 걸린 규칙 식별자는 문서 안에 230개다.

## 결정

- **§5 의 하위 절은 주제별로 두고, 하위 절 안의 규칙은 번호 오름차순으로 놓는다.**
- **하위 절 이름은 바꾸지 않는다.** 바꾸면 그 앵커를 가리키는 링크를 함께 고친다.
- **폐지한 규칙은 §5 마지막 하위 절 "폐지한 규칙"에 번호순으로 둔다.** 지우지 않고 식별자를 남기는 것은 그대로다.
- **규칙마다 앵커를 두지 않는다.** 규칙 머리는 굵은 식별자(`- **{앞말}-R{번호}** — …`) 그대로다.
- 배치의 정본은 [`specs/README` §3 규칙 2](../specs/README.md#3-쓰는-규칙)다.

## 결과

- 링크로 들어오면 하위 절 맨 위에 떨어지고, 번호를 따라 내려가 규칙을 찾는다. 하위 절과 규칙이 짧아질수록([ADR-0329](0329-a-large-rule-is-split-into-one-judgement-each-and-its-identifier-stays-as-a-group-head-covering-the-sub-rules.md)) 떨어진 자리에서 가깝다.
- 글자로 된 인용은 Spec 을 열고 식별자로 찾는다. 식별자는 문서 안에 하나뿐이다.
- 폐지한 규칙을 모은 기존 하위 절 "옮긴 규칙"은 "폐지한 규칙"이 되고, 그 앵커를 가리키는 링크를 함께 고친다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| §5 를 하위 절 없이 번호순으로 | 하위 절 앵커 링크가 모두 깨지고, 주제별로 읽는 길을 잃는다 |
| 지금 배치를 두고 폐지 규칙만 끝으로 | 하위 절 안에서 번호가 뛰는 자리가 남는다 |
| 규칙마다 식별자만 든 `####` 제목 | 앵커는 고정되지만 규칙 535개의 머리를 모두 바꾸고 목차가 규칙 수만큼 길어진다. 링크로 걸린 인용은 230개뿐이다 |
| 규칙마다 HTML 앵커와 검사기 확장 | 검사기 · 시험이 늘고, GitHub 에서의 이동을 따로 확인해야 한다 |

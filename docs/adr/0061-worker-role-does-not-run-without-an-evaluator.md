# ADR-0061: 작업 역할은 평가기 없이 운영하지 않고, 그 기동 검사는 운영 평가기의 설정과 함께 둔다

- 상태: 승인
- 날짜: 2026-11-02
- 근거: [이슈 #69](https://github.com/Theia0382/yozm-news/issues/69) — 평가 작업을 만들며 비로컬 배포(`deploy/compose.yaml` 의 `web,worker`)에 평가기 빈이 없음과 CI 배포 스모크를 확인. 구현 `a62ae65`
- 관련: [ADR-0012](0012-swappable-external-dependencies.md)(외부 의존성 교체 · 비활성 — 평가기 부분을 이 ADR 이 대체한다), [ADR-0057](0057-local-substitutes-registered-only-in-local-profile-without-operator-switch.md)(로컬 대체물 — 구현이 없을 때의 동작은 포트를 쓰는 쪽이 정한다), [ADR-0002](0002-shared-evaluation-with-jev.md)

## 맥락

- ADR-0012 는 외부 서비스를 모두 설정으로 교체하거나 끌 수 있게 하고, 결과로 "Jev 키 없이도 서비스를 띄울 수 있다 — Jev 가 없으면 대체 평가기를 써야 한다"고 적었다.
- 공유 평가의 결과는 모든 사용자의 후보 선별 · 주제별 보도량 · 사건 묶기의 입력이다. 평가가 없으면 다이제스트 · 히스토리가 성립하지 않는다 — 평가기는 이 프로그램의 핵심 요소다.
- 운영 대체 평가기는 없다. 로컬 대체물은 `local` 에서만 등록된다(ADR-0057).
- 운영 평가기(Jev 구현)와 그 키 설정은 평가 작업과 다른 이슈에서 만든다. 평가 작업이 먼저 들어가면 그 사이 배포 구성에는 평가기 빈이 없다.

## 결정

- **평가기는 교체만 하고 끄지 않는다. 작업 역할은 평가기 없이 운영하지 않는다.** 평가 작업을 하는 프로세스에 평가기가 없는 구성은 운영 구성이 아니다.
- **기동 검사는 운영 평가기의 설정(키)이 생기는 자리에 둔다.** 설정이 없으면 작업 역할이 기동하지 않는다. 키의 형식은 기동 때, 키가 맞는지는 평가 때(평가기 사용 불가 — 회차 멈춤) 드러난다.
- 화면 역할만 띄우는 프로세스는 평가기를 요구하지 않는다.

## 결과

- 평가기 없이 작업 역할을 띄운 운영이 조용히 대기만 쌓는 상태가 운영 평가기의 설정이 생긴 뒤에는 없다.
- 셀프 호스팅 운영자는 평가기 키를 마련해야 작업 역할을 띄울 수 있다. 배포 스모크 · 배포 예시에도 평가기 키 자리가 필요하다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 평가기 없는 운영을 허용한다 — 작업이 건너뛰고 경고하며 기사는 대기에 쌓인다 | 평가는 핵심 요소라 평가 없는 운영은 서비스가 성립하지 않는다 |
| 평가 작업을 만드는 변경에서 바로 기동을 막는다 | 운영 평가기가 생기기 전까지 배포 구성이 뜨지 않아 배포 스모크가 깨진다 |
| 운영 평가기를 먼저 만들고 평가 작업이 처음부터 평가기를 요구한다 | 평가 작업이 운영 평가기(외부 계정 · 공식 자료 확인)를 기다린다 |
| 평가기가 없으면 늘 "사용 불가"를 돌려주는 구현을 등록한다 | 대체물도 운영 구현도 아닌 포트 구현이 운영에 생기고, 평가기 없는 운영을 허용하는 것과 같다 |

# ADR-0232: 생성 중인 다이제스트는 다시 시작하지 않고, 임대가 지난 생성과 시작 기한이 지난 예약은 중단 실패로 끝낸다

- 상태: 승인
- 날짜: 2026-11-18
- 근거: [이슈 #178](https://github.com/Theia0382/yozm-news/issues/178) — 수용 기준 "여러 worker 에서 같은 생성이 두 번 돌지 않음". 구현 커밋 `d4381dc`(다시 시작하지 않음 · 끝내기 정본) · `d782c38`(거두기 · 임대 · `llm` 의 최악 시간)

## 맥락

- 생성은 행을 잠근 트랜잭션 밖에서 공급자를 부른다. 생성 중인 행을 다시 부르면 처음부터 다시 하던 규칙(digest Spec 의 규칙 — ADR 에 없던 것)은 결과를 하나로 남기지만, 두 실행이 겹치면 공급자 호출(사용자 비용)이 두 번이다.
- 작업 서버(JobRunr 9)는 재시도 0 이면 고아 작업을 다시 돌리지 않고 같은 작업 ID 의 등록을 건너뛴다 — 겹침을 라이브러리 동작 · 작업 설정만으로 막으면 그 둘이 바뀔 때 비용이 두 번 나간다.
- 생성 호출 한 번은 마감 180초로 네 번까지 보내고 그 사이를 60초까지 기다린다 — 최악 15분, 다시 묻기를 더하면 30분이다.
- 등록 전에 멈추거나 시작 전에 거듭 실패한 예약은 끝나지 않고 남아, 그 사용자의 수동 생성을 막는다.

## 결정

- **생성은 생성을 기다리는 다이제스트만 시작한다** — 생성 중이면 아무것도 하지 않고 그 상태를 돌려준다. 같은 다이제스트의 생성기 호출은 하나다.
- **시작한 지 임대(생성 호출 최악 × 2 + 10분 = 40분)가 지나도 생성 중이면 중단 실패(`INTERRUPTED`)로 끝내고 다시 돌리지 않는다** — 생성기를 부른 뒤 멈춘 생성을 다시 돌리면 비용을 되풀이할 수 있다. 임대는 `llm` 이 공개한 최악 시간에서 계산한다.
- **등록한 지 15분이 지나도 시작되지 않은 예약은 새 토큰으로 다시 등록하고, 만든 지 1시간(시작 기한)이 지났으면 중단 실패로 끝낸다** — 생성기를 부르기 전이라 다시 등록은 비용이 없고, 기한이 끝없는 재등록을 막는다.
- 거두기는 5분마다 돌고, 행마다 잠근 뒤 조건을 다시 본다. 실패는 다른 실패와 같은 알림이 된다.

## 결과

- 생성기 뒤에서 예외가 나 남은 행은 길어야 임대 뒤에 실패로 끝나고 알림이 간다 — 사용자는 수동 생성으로 다시 받는다.
- 시작 기한은 회차 간격 · 등록 기다림 때문에 실제로는 1시간 20분 안에 닿는다.
- 생성 마감이 측정으로 바뀌면 임대가 따라간다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 작업 ID 하나와 작업 서버의 동작에 맡긴다 | 보장이 라이브러리 동작 · 재시도 설정에 기대 바뀌면 비용이 두 번 나간다 |
| 임대가 지난 생성을 정한 횟수 · 끝없이 다시 돌린다 | 생성기 뒤 예외가 비용을 되풀이한다 |
| 다시 등록 횟수 칸으로 상한 | 칸이 하나 늘고, 만든 시각으로 같은 일을 한다 |
| 다시 등록의 상한을 두지 않는다 | 끝없이 다시 등록되고 그동안 수동 생성이 막히며 알림도 없다 |

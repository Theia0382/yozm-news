# ADR-0141: 초대 링크는 이메일에 묶지 않은 7일 일회용 링크이고, 토큰은 링크의 조각에 담아 다이제스트로만 저장한다

- 상태: 승인
- 날짜: 2026-11-13
- 근거: [이슈 #147](https://github.com/Theia0382/yozm-news/issues/147) — 구현 `d0319b6` · `de5118c`
- 관련: [ADR-0048](0048-sign-up-closed-by-default-with-invitations-and-operator-bootstrap.md)(초대 링크 — 일회용 · 만료 · 해시 저장 · 취소 가능. 만료 값 · 저장 · 화면을 정한다), [ADR-0011](0011-no-email-in-v1.md)(메일 없음 · 미인증 이메일)

## 맥락

- 닫힌 가입에서는 운영자가 만든 일회용 · 만료 있는 링크를 직접 전해 사람을 들인다([ADR-0048](0048-sign-up-closed-by-default-with-invitations-and-operator-bootstrap.md)). 메일을 보내지 않고 이메일은 미인증이다([ADR-0011](0011-no-email-in-v1.md)).
- 링크가 주소창 · 서버 로그 · `Referer` 에 남으면 토큰이 새어 나간다.
- 앱은 자기 바깥 주소를 모른다.

## 결정

- **초대를 이메일에 묶지 않는다.** 링크를 가진 사람이 자기 이메일로 한 번 가입한다. 운영자는 발급 때 메모(선택)를 붙여 목록에서 가르고, 쓴 초대는 목록에 가입한 계정의 이메일을 보인다.
- **만료는 발급 뒤 7일 고정이다.** 운영자는 유효한 초대를 취소한다.
- **토큰은 128비트 무작위 값이고, 링크의 조각(`/invite#토큰`)에 담는다.** 저장 · 대조는 SHA-256 다이제스트로만 한다. 토큰은 발급 응답에 한 번만 나간다.
- **링크는 운영자 화면이 자기 주소로 만든다** — 주소까지 링크 전체를 보인다.

## 결과

- 이메일 오타로 가입이 막히지 않는다. 링크가 새면 그 링크로 누구나 한 번 가입한다 — 일회용 · 7일 · 취소로 범위를 줄이고, 얻는 것은 일반 사용자 계정이다.
- 조각은 서버로 가지 않아 서버 로그 · `Referer` 에 토큰이 남지 않는다. 화면이 조각을 읽어 상태 확인 · 가입 요청 본문에 싣는다.
- 운영자가 내부 주소로 운영자 화면을 열면 링크도 내부 주소다 — 운영 안내가 바깥에서 닿는 주소로 열라고 한다.
- 늦게 여는 사람에게는 다시 발급한다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 운영자가 이메일을 적어 발급하고 그 이메일로만 가입 | 오타가 가입을 막고, 미인증 이메일이라 막는 힘이 작다 |
| 운영자가 발급 때 만료를 고른다 | 요청 칸 · 범위 검사 · 화면 선택이 는다. 늦으면 다시 발급하면 된다 |
| 토큰을 링크의 경로 · 질의에 둔다 | 서버 로그 · `Referer` 에 토큰이 남는다 |
| 서버가 바깥 주소 설정으로 링크를 만든다 | 설정이 하나 늘고, 운영자 화면이 이미 바깥 주소로 열려 있다 |

# ADR-0291: 정리에 쓴 토큰은 개인 흐름 화면에 마지막 정리와 지금까지의 합으로 보인다

- 상태: 승인
- 날짜: 2026-11-23
- 근거: [이슈 #245](https://github.com/Theia0382/yozm-news/issues/245) — 정리는 사용자의 키로 부르는 두 번째 생성 호출이라 그 비용도 사용자에게 보여야 한다. 리드가 자리와 꼴을 다이제스트와 같게 정했다. 구현 커밋 `4e6da46` · `83665ae` · `fc8a373`
- 관련: [ADR-0239](0239-digest-screens-show-tokens-of-the-visible-digest-and-the-sum-of-every-attempt-of-the-date-without-prices.md)(보충 — 다이제스트 화면 밖의 사용자 비용), [ADR-0288](0288-summaries-are-made-after-a-digest-ends-only-for-changed-flows-and-extended-with-new-events.md)(시도 기록)

## 맥락

- 다이제스트 화면은 맨 아래 작은 회색 줄로 보이는 다이제스트의 모델 · 토큰과 그 날짜 모든 시도의 합을 보인다.
- 정리는 흐름마다 여러 번 고쳐 쓰고, 실패한 호출과 결과를 버린 호출도 토큰을 쓴다.

## 결정

- **개인 흐름 화면의 맨 아래에 작은 회색 줄 둘을 둔다.** 첫 줄은 마지막 정리의 모델 · 입력 토큰 · 출력 토큰이고, 둘째 줄은 그 흐름을 정리한 호출 수와 모든 호출의 토큰 합이다. 호출이 한 번이면 둘째 줄은 없다.
- **합은 저장한 호출 · 결과를 버린 호출 · 실패한 호출을 모두 센다.** 공급자가 토큰을 알려 주지 않은 호출은 수에만 든다.
- **금액으로 바꾸지 않는다.**
- **탭의 카드에는 토큰을 두지 않는다.**

## 결과

- 정리를 지웠다가 다시 만든 흐름의 합은 이어진다 — 시도 기록은 정리와 따로 남는다.
- 사용자 스토리라인이 사라지면 그 합도 사라진다. 사용자 전체의 정리 비용 합은 어느 화면에도 없다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 마지막 정리의 토큰만 | 고쳐 쓰기 · 실패의 비용이 보이지 않는다 |
| 탭에 모든 흐름의 합을 둔다 | 다이제스트 화면과 꼴이 달라지고, 사라진 흐름의 몫을 따로 남겨야 한다 |
| 보이지 않는다 | 사용자 비용이 드는 일이 사용자에게 보이지 않는다 |

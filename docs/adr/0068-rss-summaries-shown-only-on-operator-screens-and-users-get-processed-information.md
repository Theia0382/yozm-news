# ADR-0068: RSS 요약문은 운영자 화면에만 보이고, 인스턴스 사용자와 외부 API 에는 가공한 정보만 낸다

- 상태: 승인
- 날짜: 2026-11-04
- 근거: [이슈 #73](https://github.com/Theia0382/yozm-news/issues/73) — 기점 `45b16f3` 의 노출 규칙(ADR-0029 · [security.md](../security.md) · [overview.md](../overview.md) · [data-model.md](../data-model.md) · [architecture.md](../architecture.md))을 대조. 표본 검수 화면이 보일 기사 정보를 정하면서 결정
- 관련: [ADR-0029](0029-indefinite-summary-retention-with-optional-deletion.md)(요약문 노출 금지 — 이 ADR 이 부분 대체한다), [ADR-0047](0047-self-hosted-software-run-by-instance-operators.md)(개인이 자기 서버에 띄워 쓰는 소프트웨어 — 근거)

## 맥락

- ADR-0029 는 RSS 요약문을 화면 · 외부 API 에 노출하지 않는다는 규칙을 그대로 두었다. 이 규칙은 언론사에서 받은 요약문을 공중에 재배포하면 RSS 이용조건에 걸린다는 이유에서 나왔다.
- 같은 이유로 요즘뉴스는 개인이 자기 서버에 띄워 쓰는 소프트웨어가 됐다(ADR-0047). 인스턴스는 운영자와 운영자가 허락한 몇 사람이 쓰고, 언론사가 그리는 개인 구독에 가깝다.
- 운영자는 공유 평가를 검수해 태그 기준을 정한다. 평가기는 제목 · 요약문 · 출처 · 피드 섹션 · RSS 카테고리를 보고 판정하므로, 판정이 맞는지 보려면 같은 입력이 필요하다.
- 피드 섹션 · RSS 카테고리는 요약문은 아니지만 지금 화면에 보이는 정보의 닫힌 목록(LLM 종합문 · 기사 제목 · 출처 · 발행 시각 · 원문 링크)에 없다.

## 결정

- **운영자 화면은 RSS 요약문 원문 · 피드 섹션 · RSS 카테고리를 보일 수 있다.** 운영자 경로(`/api/admin/**` 와 그 화면)에 한한다.
- **인스턴스 사용자의 화면과 외부 API 에는 가공한 정보만 낸다** — LLM 종합문, 기사 제목, 출처, 발행 시각, 원문 링크. 요약문 원문은 내지 않는다.
- 기사 본문을 재게시하지 않고 공중에 재배포하지 않는다. 언론사가 삭제를 요청하면 요약문을 지우는 운영자 기능은 그대로 둔다.
- 소스의 이용조건 판단은 인스턴스 운영자 몫이다(ADR-0047).

## 결과

- 운영자가 평가 결과를 평가기와 같은 입력으로 검수한다.
- 사용자 화면 · 외부 API 의 노출 목록은 그대로다.
- 운영자 화면이 요약문을 내므로, 운영자 경로의 인가(ADR-0043)가 요약문의 노출 범위를 정한다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 노출 금지를 그대로 두고 운영자 화면도 제목 · 출처 · 원문 링크만 보인다 | 평가기가 본 입력을 운영자가 보지 못해, 판정이 맞는지 원문 페이지를 열어 짐작한다. 원문 페이지와 피드의 요약문이 다를 수 있다 |
| 인스턴스 사용자 화면에도 요약문을 보인다 | 사용자에게 내는 것은 원문이 아니라 요즘뉴스가 가공한 정보로 한정한다 |
| 외부 API 에도 요약문을 낸다 | 같은 이유로 가공한 정보로 한정한다 |

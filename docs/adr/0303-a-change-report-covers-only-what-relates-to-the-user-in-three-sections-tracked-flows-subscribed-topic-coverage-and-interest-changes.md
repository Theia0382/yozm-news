# ADR-0303: 변화 리포트는 그 사용자와 관계된 것만 다루고, 갈래는 추적한 흐름 · 구독 주제 보도량 · 관심 변화 셋이다

- 상태: 승인. 부분 대체 — 결과의 `EMPTY` 조건([ADR-0336](0336-change-report-interest-lines-are-only-the-changed-ones-and-without-a-change-there-is-no-interest-section.md))
- 날짜: 2026-11-24
- 근거: [이슈 #238](https://github.com/Theia0382/yozm-news/issues/238) — 기점 `f1d0938` 의 리포트 입력 목록(pipeline §10)을 목적(ADR-0025)과 사용자 스토리라인(user Spec)에 대조해 재료의 범위와 갈래를 정함
- 관련: [ADR-0273](0273-change-reports-are-written-in-fixed-sections-per-material-kind-keyed-as-required-fields.md)(갈래 집합과 맥락의 입력 갈래 넷 — 부분 대체), [ADR-0103](0103-big-judgement-on-storylines-and-the-storyline-milestone-right-after-event-clustering-takes-over-big-events.md)(결정 "변화 리포트의 보도량이 쓰는 '큰' 것" — 부분 대체), [ADR-0025](0025-long-term-personal-news-history-in-v1.md)(변화 리포트의 목적 — 개인 뉴스 히스토리)

## 맥락

- 변화 리포트는 한 사용자의 한 기간에 무엇이 달라졌는지 정리하는 개인 뉴스 히스토리의 기능이다(ADR-0025).
- 리포트의 입력 목록은 개인 쪽이 사용자별 이슈였던 설계에서 시작했고, 개인 쪽이 스토리라인 구독을 거쳐 사용자 스토리라인으로 바뀌는 동안 낱말만 옮겨졌다. 그 목록에는 공용 큰 스토리라인의 보도량과 구독 밖에서 새로 나타난 주제가 있다.
- 큰 판정은 구독과 무관하게 알릴 만한 흐름을 인스턴스 전체를 보고 고른다. 다이제스트는 큰 슬롯으로 이를 날마다 알리고, 사용자가 반응하거나 추적하면 그 흐름은 사용자 스토리라인이 된다.
- 사용자 스토리라인 가운데 관심 흐름(추적 중인 것 포함)은 그 사용자의 키로 정리(제목 · 흐름 요약 · 최근 전개)를 갖는다. 공용 큰 스토리라인에는 정리가 없다.
- 사용자 범위로 좁히면 "새로 나타난 것과 줄어든 것"은 다른 갈래와 겹친다 — 구독 주제의 증감은 보도량의 직전 비교가, 관심의 생김 · 사라짐과 흐름이 보이게 되고 사라지는 것은 관심 변화가, 추적한 흐름의 보도 감소는 추적한 흐름의 변화가 다룬다.

## 결정

- **리포트는 그 사용자와 관계된 것만 재료로 삼는다.** 추적 중인 사용자 스토리라인과 관심 흐름, 구독 주제와 관심 주제다. 공용 큰 스토리라인과 구독 밖 주제는 읽지 않는다.
- **추적한 흐름은 추적 중인 사용자 스토리라인이다.** 사용자가 누른 스토리라인(추적 씨앗)이 아니라 이어짐을 따라간 흐름 전체로, 다이제스트의 추적과 같은 집합이다.
- **갈래는 셋이다** — 추적한 흐름의 변화(`STORYLINES`) · 구독 주제의 보도량과 직전 비교(`COVERAGE`) · 관심 변화(`INTERESTS`). "새로 나타남 · 줄어듦"은 각 갈래 안의 판정으로 보인다.

규칙은 [report Spec](../specs/report.md#재료) report-R14 · R15 에 있다.

## 결과

- 리포트의 모든 흐름이 사용자 스토리라인이라 설명할 글(정리)이 설계상 있다.
> 부분 대체(첫 문장) — [ADR-0336](0336-change-report-interest-lines-are-only-the-changed-ones-and-without-a-change-there-is-no-interest-section.md). 지금 상태: [report Spec](../specs/report.md#재료) report-R14
- 구독 주제 · 추적 흐름 · 관심 신호가 모두 없는 사용자는 갈래가 하나도 없어 리포트가 `EMPTY` 다. 가입 기본값에는 주제 구독이 없다.
- "이번 기간 세상의 큰 흐름"은 리포트에 배경으로 나오지 않는다 — 다이제스트 큰 슬롯이 알린다(큰 슬롯 수를 0 으로 둔 사용자는 그것도 없다).
- 갈래가 하나 줄어 종류 enum, 출력 서술, 저장의 종류 제약을 함께 바꾼다.
- 기간 안에 추적을 뺀 흐름은 추적한 흐름의 변화에 들지 않는다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 입력 목록 그대로 — 큰 스토리라인 보도량 · 구독 밖에서 새로 나타난 주제 포함 | 사용자와 관계없는 분류가 섞이고, 정리가 없는 흐름을 리포트가 따로 설명해야 한다 |
| 갈래 넷을 두고 "새로 나타난 것과 줄어든 것"을 사용자 범위로 | 다른 세 갈래의 비교 결과를 다시 모은 요약이 되어 출력이 같은 내용을 두 번 쓰고, 재료가 빈 날이 많다 |
| 갈래 둘 — 대상별 "내 흐름" · "내 주제" | 세상의 보도량과 나의 관심이라는 다른 종류의 수가 한 섹션에 섞인다 |
| 추적한 흐름 = 사용자가 누른 스토리라인 | 흐름이 이어져 뒤 흐름으로 넘어가면 옛 흐름만 보고, 다이제스트의 추적과 다른 집합이 된다 |

# ADR-0121: 스토리라인 잇기의 점수는 사건 중심 코사인과 IDF 로 가중한 핵심 말 겹침이고, 시각 감쇠 · Jev · 주제 태그를 쓰지 않는다

- 상태: 승인
- 날짜: 2026-11-12
- 근거: [이슈 #121](https://github.com/Theia0382/yozm-news/issues/121) — 스토리라인 평가 세트로 임시 잇기 규칙과 후보 방법(점수의 재료 · 스토리라인과 견주는 법 · 붙이는 수 · 짝 기준 · 애매한 구간의 Jev 판정)을 견주고 리드와 정함
- 관련: [ADR-0106](0106-provisional-storyline-linking-opens-only-with-a-partner-event-and-adds-the-single-best-storyline-without-removal.md)(결정의 점수 산식과 "이 규칙은 기준선이다. 잇는 방법을 평가 세트로 정하면 대체될 수 있다" — 부분 대체), [ADR-0101](0101-shared-storylines-connect-events-and-the-personal-side-is-storyline-subscriptions-and-interests.md)(결정 "소속을 정하는 방법은 스토리라인을 구현할 때 정한다" — 보충), [ADR-0107](0107-storyline-state-is-judged-at-query-time-from-the-last-article-and-an-ended-storyline-still-links.md)(맥락의 잇기 도달 범위 — 보충), [ADR-0105](0105-storylines-link-incrementally-from-event-change-notifications-and-events-publish-changed-event-ids.md)(이 규칙이 도는 틀 — 잇기의 재료를 `event` 의 공개 조회로 읽는다), [ADR-0110](0110-storyline-evaluation-labels-system-events-of-a-fixed-dump-and-measures-overlapping-clusters-from-random-seed-events.md) · [ADR-0111](0111-storyline-gold-links-by-matter-with-mixed-events-on-their-central-happening-and-events-without-a-happening-following-their-matter.md)(견준 평가 세트), [ADR-0096](0096-instance-bound-evaluation-data-kept-out-of-the-public-repository-and-defaults-cite-only-the-evaluation-set.md)(근거 수치를 공개 문서에 적지 않는다)

## 맥락

- 임시 잇기 규칙은 잇는 방법을 평가 세트로 견줄 기준선이었다([ADR-0106](0106-provisional-storyline-linking-opens-only-with-a-partner-event-and-adds-the-single-best-storyline-without-removal.md)). 평가 세트가 생겨 기준선과 후보 방법을 같은 고정 덤프에서 견줬다.
- 기준선은 평가 세트에서 서로 다른 사안의 사건을 큰 스토리라인 몇 개로 뭉쳤다. 원인은 둘이다.
  - 기본 임베딩 모델의 사건 중심 코사인은 같은 사안의 쌍과 다른 사안의 쌍이 좁은 범위에 몰려 있어, 코사인만으로는 둘이 잘 갈리지 않는다.
  - 핵심 말 겹침을 말의 수로 세어 흔한 말과 드문 말의 무게가 같다. 스토리라인이 커지면 합친 핵심 말의 상위가 어느 사건에나 있는 흔한 말로 채워져, 같은 분야의 사건이 계속 붙는다.
- 스토리라인에 들지 않는 사건이 많아, 전체 지표는 아무것도 잇지 않아도 높다. 그래서 스토리라인이 있는 씨앗과 없는 씨앗을 나눠 보고, 시각이 먼 쌍의 재현율을 함께 봤다.
- 잇기는 생성형 LLM 없이 운영자 비용으로 돈다([ADR-0101](0101-shared-storylines-connect-events-and-the-personal-side-is-storyline-subscriptions-and-interests.md)). Jev 판정은 호출마다 운영자 비용이다.
- 평가 세트는 며칠치 고정 덤프다. 몇 주에 걸친 전개를 담지 못한다.

## 결정

- **점수는 (1 − w) × 코사인 + w × 핵심 말 겹침이고, 겹침은 말의 무게(IDF)로 센다.** 겹침은 겹친 말의 무게 합 ÷ 판정할 사건의 말의 무게 합이다. 많은 사건에 있는 말일수록 무게가 작아, 흔한 말만 겹치는 사건은 겹침이 작다.
- **말의 흔함은 판정할 사건의 시각 ± 시간 창 안의 사건으로 센다.** 후보를 찾는 범위와 같다. `event` 는 말마다 그 말을 가진 사건 수와 범위 안의 사건 수만 내고, 무게의 식은 `storyline` 이 갖는다.
- **시각 감쇠를 점수에서 뺀다.** 시각 차는 시간 창을 넘는지만 본다.
- **Jev 판정과 주제 태그를 쓰지 않는다.** `storyline` 은 `evaluation` · `tag` 에 의존하지 않는다.
- **판정의 꼴은 임시 규칙의 것을 그대로 확정한다.** 스토리라인 표현(중심 · 합친 핵심 말)과 견주고, 기준 이상 가운데 가장 높은 하나를 더하며 빼지 않고, 주 소속을 두지 않고, 사건이 바뀔 때마다 판정하고, 붙일 곳 없는 사건은 붙이기와 같은 기준으로 소속 없는 이웃과 짝을 지어 연다. 다시 넣기와 정돈도 그대로다.
- **가중치 w 는 코드 상수, 기준 점수와 시간 창은 설정이고, 가중치와 기준 점수의 값은 평가 세트로 정했다.** 이 값들은 측정 전 목표다 — 운영하면서 다시 본다. 시간 창은 평가 세트의 기간으로 가를 수 없어 임시 규칙의 값을 그대로 둔다. 차이는 씨앗 단위로 다시 뽑은 구간으로 보고, 구간 안의 차이는 같은 품질로 본다. 같은 품질의 후보 가운데서는 구조를 덜 바꾸고 운영자 비용이 없는 쪽을 고른다. 값의 정본은 [storyline Spec §5](../specs/storyline.md#잇기-규칙) · [§7](../specs/storyline.md#7-설정)이고, 근거 수치는 공개 문서에 적지 않는다([ADR-0096](0096-instance-bound-evaluation-data-kept-out-of-the-public-repository-and-defaults-cite-only-the-evaluation-set.md)).

## 결과

- 기준 점수의 눈금이 바뀐다. 설정 키와 범위는 그대로이고 값의 뜻이 달라, 기준을 덮어쓴 인스턴스는 값을 다시 정해야 한다 — 옛 눈금의 값을 그대로 두면 거의 모든 사건이 기준을 넘는다.
- 코사인 하한이 높아져 후보 스토리라인 · 이웃 사건 조회가 실제로 걸러진다.
- 기준값은 기본 임베딩 모델의 코사인 범위에 묶이고, 작은 차이에 민감하다. 다른 모델이나 소스 구성에서는 운영자가 맞춘다.
- 옛 규칙으로 붙은 소속은 남는다. 지난 소속은 다시 판정하지 않고, 스토리라인을 비우고 다시 잇는 운영 기능은 없다.
- 시각 감쇠가 없어 잇기의 도달 범위는 시간 창이다. 끝난 스토리라인도 창 안이면 그대로 후보다([ADR-0107](0107-storyline-state-is-judged-at-query-time-from-the-last-article-and-an-ended-storyline-still-links.md)).
- `event` 의 공개 조회가 하나 늘고(말 수 조회), 판정마다 그 조회가 판정의 모듈 잠금 안에서 돈다.
- 재지 못한 것이 남는다.
  - 몇 주에 걸친 전개 — 내용이 바뀌어 가는 흐름의 끝이 처음 쪽에 머문 스토리라인 중심과 얼마나 가까운지, 감쇠 없는 창이 긴 기간에서 어떻게 움직이는지
  - 사건이 자라는 동안의 판정 — 기사가 적을 때의 판정이 소속으로 남는 정도. 평가는 최종 상태의 사건을 판정했다
  - 구성 사건이 자라 표현이 움직일 때 기다리는 사건을 다시 판정하지 않는 것의 영향([ADR-0106](0106-provisional-storyline-linking-opens-only-with-a-partner-event-and-adds-the-single-best-storyline-without-removal.md) 이 다시 볼 자리로 남긴 대안)
  - 말의 흔함을 세는 범위 — 큰 흐름이 창 안에서 자기 말을 흔하게 만드는 효과와, 사건이 쌓였을 때의 말 수 조회 비용
- 운영하면서 볼 것은 [미결 사항](../open-questions.md) 35 에 있다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 점수의 애매한 구간만 Jev 에 묻는다 | 붙이기 후보에서는 Jev 의 확률이 점수보다 잘 갈랐지만 전체 품질의 이득이 구간 안이었고, 짝 후보에서는 점수와 비슷했다. 후보의 요약문이나 판정할 쪽 기사를 더 넣어도 같았다. 판정마다 운영자 비용이 들고, 판정 연산 · 트랜잭션 밖 흐름 · 문구와 구간의 값이 는다. 더 긴 표본에서 다시 볼 수 있다 — 이 점수가 그때 애매한 구간의 바탕이 된다 |
| 기사 주제 태그의 겹침을 점수에 더한다 | 평가 세트에서 이득이 없었고, `storyline` → `tag` 의존과 공개 조회가 생긴다 |
| 구성 사건 하나하나와 견줘 가장 가까운 값을 쓴다(가장 가까운 이웃의 스토리라인에 붙이기) | 품질이 구간 안에서 같았고 씨앗을 나눈 교차 확인에서 우위가 유지되지 않았다. 기준이 사건 하나와의 거리로 우회되어 가장 큰 스토리라인이 더 커졌고, 판정 비용이 스토리라인 크기에 비례한다. 긴 전개에서 나은지는 더 긴 표본으로만 가릴 수 있다 |
| 기준 이상을 둘까지 붙인다 | 정밀도가 내리고 재현율은 그대로였다 |
| 소속에 주 소속 표시를 둔다 | 쓰는 곳(여러 스토리라인의 합계 규칙)이 아직 없다. 필요해지면 소속의 판정 근거(점수)에서 끌어낼 수 있다 |
| 사건이 닫힐 때 한 번만 판정한다 | 닫는 기간 동안 사건이 스토리라인에 들지 않아, 그날의 다이제스트 · 타임라인이 쓰지 못한다 |
| 짝으로 여는 기준을 붙이기 기준보다 높게 따로 둔다 | 스토리라인에 없어야 할 사건의 묶임은 줄지만 스토리라인에 있어야 할 사건의 재현율이 내려 전체로는 낫지 않았다. 값 조정은 기준 하나로 먼저 한다 |
| 겹침을 두 쪽 말의 합집합으로 나눈다(가중 자카드) | 품질이 구간 안에서 같았다. 견줄 것의 말까지 무게가 필요해 판정마다 후보 전부의 말을 `event` 에 묻고, 코사인 하한이 낮아 후보를 거의 거르지 못한다 |
| 말의 흔함을 모든 사건으로 센다 | 평가 세트의 기간이 시간 창보다 짧아 창으로 센 것과 같은 조건이었다 — 사건이 쌓인 뒤의 무게는 재지 않은 외삽이 되고, 말 수 조회가 읽는 행이 쌓인 사건 수에 비례해 는다 |
| 말의 흔함을 시간 창보다 긴 창이나 반감기로 센다 | 큰 흐름의 말이 덜 흔해지는 쪽이지만, 평가 세트로 가릴 수 없는 값이 는다 |
| 시각 감쇠를 남긴다 | 사건 쌍에서 시각 차는 같은 사안인지를 거의 가르지 못했다. 새 점수에 감쇠를 넣은 꼴은 재지 않았다 |
| 점수를 코사인 + 계수 × 겹침으로 두고 기준이 1 을 넘게 한다 | 같은 부등식을 0 ~ 1 의 꼴로 적을 수 있고, 기준 이력의 제약과 설정 검증을 고쳐야 한다 |
| 말의 무게를 `event` 가 계산해 낸다 | 무게의 식은 잇는 방법의 지식이다. `event` 는 수만 안다 |

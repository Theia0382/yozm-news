# ADR-0015: 뉴스 소스는 수집 프로필로 등록하고, 주요 언론사는 프리셋으로 제공한다

- 상태: 승인
- 날짜: 2026-10-25
- 관련: [ADR-0001](0001-news-source-rss.md)(운영자 큐레이션 RSS)의 등록 방식을 구체화한다

## 맥락

- v1 뉴스 소스는 운영자가 검토 · 등록한 언론사 공식 RSS 다([ADR-0001](0001-news-source-rss.md)).
- 국내 RSS 는 형식이 제각각이다. 비표준 날짜, 날짜 누락, 표준 밖 요소(`dc:date`), 깨진 XML, 본문 전체를 담은 요약문이 흔하다([조사 자료](../research/2026-10-rss-survey.md)).
- 피드 URL 만 받아 범용 규칙으로 정규화하면, 새 비표준 형식이 운영 중에 조용히 품질을 떨어뜨린다(예: 날짜가 전부 추정값으로 저장된다).
- 셀프 호스팅이 전제라서([ADR-0012](0012-swappable-external-dependencies.md)) 운영자가 개발팀이 지원하지 않는 소스(지역 매체 등)를 배포 없이 붙일 수 있어야 한다.

## 결정

### 수집 프로필

- 소스(언론사)마다 **수집 프로필**을 둔다. 수집 프로필은 그 소스의 피드를 읽고 형식을 보정하는 방법을 **선언형**으로 적은 것이다 — 피드 목록, 사전 보정 규칙(알려진 목록에서 선택), 필드 매핑, 날짜 형식과 시간대, 요약문으로 쓸 요소, 메타데이터 매핑, 기본 수집 주기.
- 프로필 형식은 하나다. 프리셋과 운영자 프로필이 같은 형식을 쓰고, 같은 엔진이 해석한다.

### 프리셋

- 주요 언론사의 수집 프로필은 개발팀이 **프리셋**으로 저장소에서 관리한다. 프리셋에는 소스 정보와 이용조건 검토일도 담는다.
- 프리셋은 그 소스의 형식 이상 사례를 재현한 합성 테스트 데이터로 검증한 뒤에만 추가 · 변경한다.
- 선언형으로 표현할 수 없는 보정이 필요하면 **프리셋에 한해** 그 소스 전용 코드를 둘 수 있다.

### 운영자

- 프리셋이 있는 소스는 운영자가 고르고 **켜고 끄기만** 한다. 피드 단위로도 켜고 끌 수 있다.
- 운영자는 프리셋을 복사하지 않고 **참조**한다. 필요한 항목만 덮어쓸 수 있고, 덮어쓴 항목은 운영자 화면에 표시한다. 덮어쓰지 않은 항목은 프리셋이 바뀌면 다음 배포에서 그대로 따라간다.
- 프리셋이 없는 소스는 운영자가 같은 형식으로 수집 프로필을 직접 작성한다. 운영자 프로필에는 코드를 넣을 수 없다.

### 활성화 관문

- 소스와 피드를 켜기 전에 서버가 한 번 받아 **미리보기**를 만든다 — 항목 수, 날짜 해석률, 요약문 길이 분포, 파싱 오류.
- 미리보기가 기준에 못 미치면 활성화하지 않는다. 프리셋을 켤 때도, 운영자 프로필을 켤 때도 같은 관문을 지난다.
- 이용조건 검토일이 없는 소스는 활성화하지 않는다([ADR-0001](0001-news-source-rss.md)). 프리셋은 개발팀이, 운영자 프로필은 운영자가 기록한다.

## 결과

- 알려진 소스의 정규화 품질은 개발팀이 테스트로 보장하고, 언론사가 형식을 바꾸면 프리셋을 고쳐 배포하면 모든 운영자에게 전달된다.
- 운영자는 배포 없이도 새 소스를 붙일 수 있다. 품질 하한은 활성화 관문이 지킨다.
- 셀프 호스팅 운영자가 만든 프로필은 저장소에 PR 로 보내 프리셋이 될 수 있다.
- 프로필 형식 · 엔진 · 프리셋 파일 · 미리보기 관문을 M1 에서 만들어야 한다. 관문 기준값과 첫 프리셋 대상은 M1 에서 정한다.
- 이 결정은 운영자의 피드 등록 방식이다. 사용자의 피드 추가는 여전히 v1 범위 밖이다([open-questions.md](../open-questions.md) #11).

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 운영자가 피드 URL 만 등록하고 서버가 범용 규칙으로 정규화 | 새 비표준 형식에 대응하려면 코드를 고쳐야 하고, 그 전까지 품질 저하가 조용히 일어난다 |
| 개발팀이 지원하는 소스만 쓰고 운영자는 켜고 끄기만 | 품질은 가장 확실하지만, 셀프 호스팅 운영자가 지원 밖 소스를 붙이려면 배포를 기다려야 한다 |
| 운영자가 프리셋을 복사해 소유 | 언론사 형식 변경에 맞춘 프리셋 수정이 운영자 복사본에 전달되지 않는다 |
| 프리셋도 선언형만 허용 | 깨진 XML 같은 특수 사례를 선언으로 모두 표현하지 못할 수 있다 |
| 미리보기만 보여 주고 활성화는 운영자 판단 | 기준 미달 피드가 켜지면 품질 저하가 운영 중에 드러난다 |

# ADR-0139: 첫 운영자는 환경 변수로만 만들고, 운영자도 값도 없으면 경고하고 기동하며, 운영자가 생긴 뒤 남은 값은 경고만 한다

- 상태: 승인
- 날짜: 2026-11-13
- 근거: [이슈 #147](https://github.com/Theia0382/yozm-news/issues/147) — 구현 `f522457`
- 관련: [ADR-0048](0048-sign-up-closed-by-default-with-invitations-and-operator-bootstrap.md)(첫 운영자 — 기동 로그의 초대 링크를 기본으로 두던 부분을 부분 대체하고, 미뤄 둔 첫 운영자 물음을 정한다), [ADR-0043](0043-admin-functions-guarded-by-env-bearer-token-until-account-roles.md)(운영 기능은 아직 운영자 토큰이 연다 — 운영자 계정 없이 뜨는 까닭), [ADR-0142](0142-invitations-and-operator-created-accounts-are-always-users-and-admins-come-only-from-the-first-admin.md)(`ADMIN` 이 생기는 길은 첫 운영자 하나)

## 맥락

- 가입은 기본으로 닫혀 있어, 운영자 계정이 없는 새 인스턴스에는 아무도 들어오지 못한다([ADR-0048](0048-sign-up-closed-by-default-with-invitations-and-operator-bootstrap.md)).
- 기동 로그에 운영자 초대 링크를 내면 값 없이도 운영자를 만들지만, 로그에 일부러 비밀을 남기고 재기동 때 앞 링크 · 링크를 내는 프로세스 · 링크의 바깥 주소를 정해야 한다. 앱은 자기 바깥 주소를 모른다.
- 운영 기능은 아직 운영자 토큰이 연다. 운영자 계정이 없는 인스턴스가 지금은 정상 상태이고, 배포 스모크 · 시험 · 기존 배포가 모두 그 상태로 뜬다.
- 역할을 나눠 여러 프로세스를 띄울 수 있다.

## 결정

- **첫 운영자는 환경 변수(이메일 · 초기 비밀번호)로만 만든다.** 기동 로그의 초대 링크는 없다. 표시 이름은 이메일의 `@` 앞부분이고, 첫 로그인에서 비밀번호를 바꾼다.
- **"운영자가 없다"는 쓰는(`ACTIVE`) `ADMIN` 계정이 없는 것이다.** 정지 · 탈퇴한 운영자만 남으면 첫 운영자 경로가 다시 열린다.
- **운영자가 없을 때:**
  - 값이 둘 다 없으면 경고 로그를 남기고 기동한다.
  - 하나만 있거나, 이메일이 아니거나, 비밀번호 규칙을 어기면 이유(변수 이름만)를 말하고 기동하지 않는다.
  - 이메일이 이미 있는 계정의 것이면 이유를 말하고 기동하지 않는다 — 그 계정을 올리지 않는다.
- **운영자가 있으면 남은 값은 무엇이든(하나만 · 규칙 위반 포함) 경고만 한다.**
- 판정과 생성은 두 역할 공통이고, DB 의 잠금 하나 안에서 한다 — 동시에 뜬 프로세스 가운데 하나만 만들고 나머지는 남은 값 경고를 낸다.

## 결과

- 로그에 비밀을 남기지 않는다. 링크에 딸린 물음(재기동 때 앞 링크 · 출력 프로세스 · 바깥 주소)이 없다.
- 운영자는 이메일 · 초기 비밀번호를 미리 정해 배포 환경 파일에 적어야 하고, 그 값은 평문으로 남는다 — 첫 로그인의 변경으로 쓸모를 없애고, 만든 뒤 지우라고 경고한다.
- 운영자 계정이 없어도 인스턴스가 뜬다. 운영자 계정이 운영의 필수가 되면(운영자 경로가 계정 세션으로 바뀌면) 이 판단을 다시 본다.
- 운영자를 모두 잃은 인스턴스는 값을 넣고 다시 띄워 운영자를 새로 만든다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 기동 로그의 운영자 초대 링크를 기본으로 두고 값을 주면 그 값으로 | 로그에 비밀이 남고, 재기동 · 여러 프로세스 · 바깥 주소의 물음을 앱이 바깥 주소를 모르는 채로 풀어야 한다 |
| 운영자도 값도 없으면 기동하지 않는다 | 배포 스모크 · 개발 구성 · 시험 컨텍스트 · 운영 중인 인스턴스가 모두 값을 가져야 한다. 운영 기능은 아직 토큰이 열어 계정 없이도 쓴다 |
| 운영자가 있어도 값을 검사해 하나만 · 위반이면 기동하지 않는다 | 쓰이지 않는 값 때문에 뜨지 않는다 — 두 변수를 함께 지워야 한다 |
| 이미 있는 이메일의 계정을 운영자로 올린다 | 이메일이 미인증이라, 운영자 이메일로 먼저 가입한 다른 사람이 운영자가 된다 |
| 정지 · 탈퇴한 운영자도 센다 | 운영자가 모두 떠나면 운영자를 만들 길이 없다 |

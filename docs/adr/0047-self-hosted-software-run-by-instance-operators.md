# ADR-0047: 요즘뉴스는 개인이 자기 서버에 띄워 쓰는 셀프 호스팅 소프트웨어이고, 소스와 함께 쓸 사람은 인스턴스 운영자가 정한다

- 상태: 승인
- 날짜: 2026-10-31
- 근거: [이슈 #55](https://github.com/Theia0382/yozm-news/issues/55) — 기점 `250d96f` 의 설계 문서 · ADR 에서 공개 서비스 전제를 전수로 찾아 정리. [이슈 #24](https://github.com/Theia0382/yozm-news/issues/24)에서 조사 자료의 국내 언론사 12곳 RSS 이용조건을 원문으로 대조(2026-10-31)
- 관련: [ADR-0003](0003-byok-personalized-digest.md)(기본 티어 검토 — 이 ADR 이 철회한다), [ADR-0006](0006-deployment-compose-cloudflare.md)(권장 시작점 — 이 ADR 이 대체한다), [ADR-0015](0015-source-presets-and-collection-profiles.md)(프리셋), [ADR-0025](0025-long-term-personal-news-history-in-v1.md)(장기 기능을 넣은 v1 — 그 끝을 이 ADR 이 다시 정한다), [ADR-0048](0048-sign-up-closed-by-default-with-invitations-and-operator-bootstrap.md)(가입 정책)

## 맥락

- 지금까지 요즘뉴스는 "누구나 가입해 쓰는 공개 서비스"로 정의돼 있었다. 그 정의에 기댄 계획이 여럿 있었다 — 공식 인스턴스를 띄울 호스팅 선택(미결 사항), 마지막 마일스톤 "공개 준비"와 완료 기준 "공개 베타 오픈", 키 없는 사용자용 저가 모델 기본 티어, 공개 전에 갖출 개인정보처리방침 · 이용약관, 공식 인스턴스 도메인.
- 첫 프리셋을 고르면서 국내 언론사 12곳의 RSS 이용조건을 원문으로 대조했다. 허용 문장이 있는 곳은 모두 범위가 "개인 이용자의 비상업적 사용" · "개인적인 구독" · "비상업적 블로그" 수준이고, 언론사가 제시하는 활용은 개인이 RSS 리더로 구독하는 것이다. 누구나 가입하는 공개 인스턴스는 "다수 이용자 대상" · "공중에 배포" 조항과 닿는다. 개인이 자기 인스턴스에서 쓰는 소프트웨어는 언론사가 그리는 이용에 가깝다.
- 공개 서비스는 처음부터 목표가 아니었다(사용자 결정).

## 결정

- **정의**: 요즘뉴스는 개인이 자기 서버에 띄워 쓰는 셀프 호스팅 뉴스 수집 · 다이제스트 소프트웨어다. 개발팀은 소프트웨어(코드 · 이미지 · 프리셋)를 배포할 뿐 공식 인스턴스를 운영하지 않는다. 어떤 소스를 켜고 누구와 함께 쓸지, 그 소스의 이용조건을 어떻게 판단할지는 각 인스턴스 운영자가 정한다. 한 인스턴스를 운영자가 허락한 몇 사람이 함께 쓸 수 있다.
- **운영자가 정하는 것**: 개발팀이 배포하는 것은 코드 · 컨테이너 이미지 · 프리셋이다. 호스팅 · 공개 경로 · 켤 소스 · 소스 이용조건 판단 · 함께 쓸 사람은 인스턴스 운영자가 정한다. 프리셋의 이용조건 검토는 개인 · 비상업 셀프 호스팅 인스턴스에서의 이용을 전제로 한다.
- **품질 기준은 그대로다**: 다중 사용자 기능과 인증 · 데이터 격리 · 키 보관 · 악용 방지의 공개 서비스 수준 기준을 유지한다. 운영자가 인스턴스를 인터넷에 열 수 있고, 한 인스턴스에 여러 사람의 데이터와 LLM 키가 모이기 때문이다.
- **v1 의 끝은 릴리스 준비다**: 마지막 마일스톤은 "릴리스 준비"다 — 탈퇴 · 데이터 삭제, 이미지 레지스트리 게시, 설치 문서, 백업 · 복구 리허설, 고지 링크(항목 목록의 정본은 [roadmap.md](../roadmap.md)). 완료 기준: 레지스트리에 게시한 이미지와 설치 문서만으로 새 호스트에 설치하고, 백업을 복원하는 리허설을 통과한 뒤 v1 을 릴리스(버전 태그)한다.
- **개인정보처리방침 · 이용약관**: 소프트웨어가 본문을 담지 않는다. 운영자가 문서 주소를 운영 설정에 적으면 가입 · 키 등록 화면과 바닥글에 링크가 나오고, 비우면 링크가 없다. 외부 전송 고지는 이와 별개로 키 등록 화면에 늘 나온다.
- **기본 티어를 지운다**: 저가 모델 기반 기본 티어 계획을 지운다. 운영자가 생성형 LLM 비용을 내는 일이고, 공개 서비스에서 가입하자마자 체험하게 하려는 것이 목적이었다. 키 없는 사용자에게 Jev 평가 결과 기반 헤드라인 목록을 보여 주는 대안은 미결로 남긴다 — 생성형 LLM 을 쓰지 않아 운영자 비용이 늘지 않는다.
- **도메인**: `yozmnews.net` 은 개발팀이 보유하는 프로젝트 도메인이다.

## 결과

- 공식 인스턴스를 띄울 호스팅 선택과 관리형 PostgreSQL 확인이 미결 사항에서 사라진다.
- 호스팅 권장([ADR-0006](0006-deployment-compose-cloudflare.md)의 서울 리전 VPS 한 대)을 철회한다. 운영 문서는 운영자 관점으로 쓴다.
- 이력 데이터는 설치된 인스턴스마다 쌓인다. 버전을 올릴 때 그 데이터를 보존하는 마이그레이션 규율이 운영자의 업그레이드 경로에 적용된다([ADR-0025](0025-long-term-personal-news-history-in-v1.md) 결과의 "공개 전부터" 대신).
- 소스 이용조건과 고지 의무의 판단은 운영자 몫이다. 개발팀은 판단 근거(수집 프로필의 검토일 `termsReviewedAt`)만 준다.
- 키 없는 사용자는 계속 키 등록 페이지만 본다([ADR-0003](0003-byok-personalized-digest.md)).

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 공식 인스턴스를 운영하는 공개 서비스(지금까지의 정의) | 언론사 이용조건의 다수 이용자 · 공중 배포 조항과 닿는다. 목표가 아니었다 |
| 개발팀이 초대제 공식 인스턴스를 운영 | 이용 형태는 줄지만 이용조건 · 개인정보의 책임 주체가 여전히 개발팀이다 |
| 단일 사용자 전용 소프트웨어(다중 사용자 기능 삭제) | 운영자가 허락한 사람과 함께 쓰는 이용을 잃고, 이미 설계한 사용자 격리 · BYOK 구조를 되돌린다 |
| 릴리스 완료 기준을 리드 인스턴스의 실사용 기간으로 | 설치 문서 · 게시 이미지 · 복구가 검증되지 않아도 통과한다. 실사용 측정은 앞 마일스톤의 완료 기준과 겹친다 |
| 방침 · 약관을 소프트웨어에 두지 않음(링크도 없음) | 고지를 두려는 운영자가 화면에 붙일 자리가 없다 |
| 운영자가 앱 안에서 방침 · 약관 본문을 작성 | 운영자 입력을 렌더링하는 화면이 생겨 입력 방어와 편집 화면이 필요하다 |
| 키 없는 사용자용 헤드라인 목록 대안도 기본 티어와 함께 철회 | 운영자 비용을 늘리지 않는 대안이라 기본 티어가 사라진 이유가 해당하지 않는다 |

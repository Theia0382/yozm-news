# ADR-0176: 체계 변경은 사용자 모르게 선호 범위를 좁히지 않는다 — 일부만 제외한 병합은 해제하고 알리고, 구독한 대분류에서 옮겨 간 중분류는 구독으로 더한다

- 상태: 승인
- 날짜: 2026-11-15
- 근거: [이슈 #151](https://github.com/Theia0382/yozm-news/issues/151) — 계보 검사(tag-R22 — 주제 계보는 같은 층인지만 본다)와 병합 대상이 원천 가운데 하나인 계보(tag-R23)를 확인
- 관련: [ADR-0175](0175-tag-preferences-follow-tag-set-activation-events-and-are-rewritten-to-active-keys.md)(선호를 활성 키로 고쳐 쓴다), [ADR-0010](0010-tag-taxonomy.md)(대분류 구독은 하위 중분류 전체)

## 맥락

- 계보 해석을 선호에 그대로 적용하면 병합의 원천 가운데 하나만 고른 사용자가 합친 키 전체를 고른 것이 된다. 구독이면 범위가 넓어지고, 제외면 사용자가 원한 기사가 사라진다.
- 주제 계보는 같은 층끼리만 잇고 대분류를 넘는 이동을 막지 않는다. 대분류 구독은 그 대분류의 지금 하위 전체라, 중분류가 다른 대분류로 옮겨 가면 구독자가 모르게 범위가 준다.

## 결정

- **구독은 계보대로 잇는다** — 병합의 원천 가운데 하나라도 구독했으면 합친 키를 구독한다.
- **제외는 병합의 원천을 모두 제외했을 때만 잇는다.** 일부만 제외했으면 합친 키를 제외하지 않고 제외했던 원천을 해제하고 알린다 — 대상이 원천 가운데 하나인 병합(`a`, `b` → `a`)에서 `a` 만 제외했어도 같다. 분할은 원천이 하나라 새 키 전부를 제외한다.
- **구독한 대분류에서 다른 대분류로 옮겨 간 중분류는 중분류 구독으로 더하고 알린다.** 대분류가 계보 없이 지워져도 그 중분류가 계보로 이어졌으면 이어진 중분류를 더하고, 대분류 구독의 해제는 알린다. 구독한 대분류 아래로 옮겨 온 중분류 행은 지운다(대분류 = 하위 전체).

## 결과

- 체계 변경이 사용자의 선호를 넓히는 일은 있어도 사용자 모르게 좁히지 않는다 — 좁아지는 쪽은 해제로 바꾸고 알린다.
- 사용자의 화면에 사용자가 직접 고르지 않은 중분류 구독이 생길 수 있다 — 알림이 그 까닭을 보인다.
- 고쳐 쓰는 규칙에 모드마다 갈래가 있다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 모드와 무관하게 계보대로 잇는다 | 지역 하나만 제외한 사용자가 합친 지역 전체를 조용히 제외한다 |
| 모드와 무관하게 원천을 모두 골랐을 때만 잇는다 | 주제 하나만 구독한 사용자가 병합 뒤 구독을 잃는다 |
| 옮겨 간 중분류를 따로 다루지 않는다(대분류 = 지금 하위 전체) | 구독자가 모르게 범위가 준다 |

# ADR-0167: 수집 항목과 외부 전송 항목은 로그인 없이 보는 고지 페이지 하나에 둔다

- 상태: 승인
- 날짜: 2026-11-14
- 근거: [이슈 #150](https://github.com/Theia0382/yozm-news/issues/150)
- 관련: [ADR-0047](0047-self-hosted-software-run-by-instance-operators.md)(외부 전송 고지는 키 등록 화면에 늘 나온다, 방침 · 약관은 운영자 링크 — 수집 항목의 자리를 이 ADR 이 정한다)

## 맥락

- 외부 전송 고지는 키 등록 화면에 늘 나온다. 수집 항목(이메일 · 관심 설정 · 관심 신호 이력 등)을 어디에 보일지는 정해지지 않았다.
- 계정이 생기는 길이 여럿이다 — 공개 가입, 초대 가입, 운영자가 만든 계정, 첫 운영자. 뒤 둘은 가입 화면을 보지 않는다.

## 결정

- **고지 페이지 하나에 수집 항목과 외부 전송 항목을 둔다.** 로그인 없이 볼 수 있다.
- 가입 · 초대 가입 · 키 · 설정 화면이 그 페이지로 링크한다. 키 화면은 외부 전송 항목을 본문에도 그대로 보인다.

## 결과

- 어느 길로 들어온 사용자든 고지에 닿고, 항목이 늘 때 고칠 자리가 하나다.
- 운영자가 둔 방침 · 약관의 링크가 붙을 자리가 생긴다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 키 등록 화면에 함께 둔다 | 키를 등록한 뒤에는 다시 보기 어렵다 |
| 가입 화면에 둔다 | 운영자가 만든 계정과 첫 운영자는 가입 화면을 보지 않는다 |

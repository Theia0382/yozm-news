# ADR-0295: 관심의 구독 신호는 노출 분모 밖 항이고, 주제의 값은 관심 있음 기준보다 작다

- 상태: 승인
- 날짜: 2026-11-23
- 근거: [이슈 #190](https://github.com/Theia0382/yozm-news/issues/190) — 측정에서 구독만 하고 반응하지 않은 주제가 관심 있음의 위쪽을 채우고, 반응한 주제는 그 아래에 있었다. 구독 신호가 노출 분모 안에 있어, 노출이 적은 주제에서는 구독 하나가 크게 들고 노출이 쌓인 주제에서는 묽어졌다. 리드가 구독 항을 분모 밖으로 빼고 값을 키 종류마다 정했다. 값은 측정 인스턴스의 반응 기록으로 정했다. 구현 커밋 `c1c4764`

## 맥락

- 관심 x 는 반응을 노출로 나눈 값이고, 구독 변경은 노출이 없는 신호라 분자에 γ 를 곱해 더했다(ADR-0222). 처음 값은 측정 전 목표였다.
- 분모 안의 구독 항은 노출에 따라 크기가 바뀐다. 노출이 0 이면 γ ÷ K, 노출이 쌓이면 그만큼 작아진다.
- 관심 있음은 관심이 기준 θ 이상인 주제이고, 관심사 히스토리의 생김 · 사라짐과 구독 제안이 그것을 본다(ADR-0226).
- 스토리라인 관심은 주제와 같은 산식과 처음 값으로 센다(ADR-0277). 흐름 추적은 사용자가 그 흐름을 따라가겠다는 신호다.

## 결정

- **관심 x = clamp(F ÷ (E + K) + γ·S, −1, 1).** 구독 항은 노출 분모 밖이다. γ 는 구독 변경 하나가 관심에 더하는 값이다.
- **주제의 γ 는 관심 있음 기준 θ 보다 작다.** 구독 하나만으로는 관심 있음이 되지 않고, 반응이 있어야 된다. 이 성질은 시험이 지킨다.
- **스토리라인의 γ 는 주제와 따로 둔다.** 추적만 한 흐름의 값이 노출이 쌓여도 묽어지지 않는다.
- 반감기 · K · β 는 그대로다.

## 결과

- 구독한 주제의 가중치는 노출과 무관하게 조금 오른다. 관심 있음 · 구독 제안 · 관심사 히스토리의 생김은 반응한 주제가 정한다.
- 추적한 흐름은 구독 항만큼 높게 시작한다. 거름 기준 아래로 가려면 반응 항이 그만큼 더 내려가야 한다 — 추적한 흐름은 추적하지 않은 흐름보다 싫어요가 더 쌓여야 걸러진다.
- 해제는 −γ 를 더한다. 구독하고 해제한 주제 · 흐름은 0 가까이로 돌아온다 — 해제가 더 최근이라 무게가 커서 조금 아래다.
- 구독 항이 클램프 앞에서 더해지므로, 반응이 이미 상한 가까이인 키에서는 구독이 더하는 값이 잘린다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 산식을 두고 γ 만 낮춘다 | 구독 항이 여전히 노출에 따라 바뀐다 — 노출이 많은 구독 주제는 구독이 거의 사라진다 |
| 구독을 관심에서 빼고 선별의 구독 필터만 쓴다 | 구독한 주제의 순위 보정이 없어지고, 흐름 추적이 흐름 관심에 들지 않는다 |
| 주제의 γ 를 관심 있음 기준 이상으로 둔다 | 구독만 한 주제가 관심 있음 · 생김으로 보여 반응한 주제를 가린다 |
| 스토리라인의 γ 를 주제와 같게 둔다 | 추적한 흐름의 순위 보정이 약해진다 |

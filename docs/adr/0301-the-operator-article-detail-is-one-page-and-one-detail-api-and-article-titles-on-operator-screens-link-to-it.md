# ADR-0301: 운영자 기사 상세는 한 페이지 · 상세 API 하나로 기사 · 평가 · 사건 소속을 싣고, 운영자 화면의 기사 제목이 그리로 잇는다

- 상태: 승인
- 날짜: 2026-11-23
- 근거: [이슈 #129](https://github.com/Theia0382/yozm-news/issues/129) — 운영자 화면에 기사 하나를 보는 곳이 없었다. 사건 상세의 기사 행은 어디로도 이어지지 않았고, 평가 상세는 평가 ID 로만 열렸다
- 관련: [ADR-0045](0045-admin-module-serves-operator-api-over-module-public-operation-apis.md)(운영자 API 는 `admin` 이 모듈의 공개 API 위에 낸다), [ADR-0068](0068-rss-summaries-shown-only-on-operator-screens-and-users-get-processed-information.md)(요약문 원문은 운영자 화면에만), [ADR-0302](0302-the-article-detail-shows-clustering-evidence-from-the-assignment-its-criteria-stored-candidates-applied-judgement-and-remaining-key-terms.md)(기사 상세가 싣는 사건 묶기 근거)

## 맥락

- 기사의 값은 `article` · `source`, 평가는 `tag`, 사건 소속은 `event`, 사건 소속 판정 원본은 `evaluation` 이 갖는다. 운영자 API 는 `admin` 이 이 모듈들의 공개 조회를 불러 맞붙인다.
- 사건 · 스토리라인 · 평가의 운영자 상세는 모두 자원 하나에 화면 하나 · 상세 API 하나다.
- 기사 하나의 평가는 태그 체계 버전마다 하나라 몇 건이고, 배정은 하나, 저장 후보는 많아야 몇 건, 배정이 반영한 판정 원본은 하나다.
- 기사를 지우면 그 기사의 평가 · 배정 · 표현 · 판정 원본을 각 모듈이 따라 지운다.

## 결정

- **기사 상세는 `/admin/articles/{ID}` 한 페이지다.** 기사 정보(제목 · 원문 링크 · 발행 시각 · 엔트리마다 출처 · 섹션 · 카테고리 · 요약문), 평가(버전마다 한 줄 — 판정 요약과 평가 상세 링크), 사건 소속(사건 링크와 배정 · 근거 · 반영한 Jev 판정), 핵심 말을 차례로 둔다. 평가 · 사건 소속을 하위 페이지로 나누지 않는다.
- **API 도 상세 하나다** — `GET /api/admin/articles/{id}`. 하위 자원(평가 · 배정)으로 나누지 않는다. 평가의 저장 행 전부 · 분포는 싣지 않고 평가 상세로 잇는다.
- **없는(지운) 기사는 404 다.** 남은 평가 · 배정 조각을 보이지 않는다. 평가 · 배정 · 표현이 없는 기사는 그 칸을 비우고 까닭을 적는다.
- **기사가 나오는 운영자 화면에서 기사 제목이 기사 상세로 잇는다** — 사건 목록 · 상세의 대표 기사와 기사 행, 스토리라인 목록 · 상세 · 큰 스토리라인의 대표 기사, 판정 기록의 판정한 기사다. 평가 상세(표본 검수 포함)는 기사 칸에 "기사 상세" 링크를 둔다. 평가 목록 행의 제목은 지금처럼 평가 상세로 잇는다. 그새 지운 기사("지운 기사 N")는 잇지 않는다.
- **기사 목록 · 검색 화면과 메뉴 항목은 두지 않는다.** 기사 ID 를 아는 운영자는 주소로 연다.

## 결과

- 상세 한 번에 공개 조회 일곱 번(기사 · 피드 이름 · 평가 · 배정 · 사건 · 판정 원본 · 핵심 말)을 부른다. 한 스냅숏이 아니다 — 조회 사이에 사라진 사건 · 지운 원본은 빈 칸이다.
- `tag` · `event` · `evaluation` 이 기사 ID · 판정 원본 ID 로 찾는 공개 조회를 하나씩 더 낸다.
- 평가 목록에서 기사 상세까지는 평가 상세를 거쳐 두 번 누른다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 기사 페이지 아래 평가 · 사건 하위 페이지 | 기사 하나의 평가 · 배정은 몇 건뿐이라 나눌 양이 아니고, 한 기사의 평가와 사건 소속을 견주려면 오가야 한다 |
| 하위 자원마다 API | 화면이 언제나 함께 부르고, 다른 운영자 상세(사건 · 스토리라인 · 평가)와 꼴이 달라진다 |
| 지운 기사도 남은 평가 · 배정을 보인다 | 남은 조각은 곧 지워질 따르기 중의 값이고, 기사 정보 없이 읽을 것이 없다 |
| 평가 목록 행에도 기사 상세 링크 | 한 행에 링크 대상이 둘이 되고, 행 제목이 평가 상세로 가는 지금 꼴과 섞인다 |

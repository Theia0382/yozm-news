# ADR-0289: 보이는 흐름은 정리가 있는 사용자 스토리라인이고, 정리 작업이 만들고 지운다

- 상태: 승인
- 날짜: 2026-11-23
- 근거: [이슈 #245](https://github.com/Theia0382/yozm-news/issues/245) — 탭 · 다이제스트 항목 · 관심사 히스토리가 "보이는 흐름"을 같은 뜻으로 써야 하고, 화면을 열 때마다 관심 재료를 읽지 않아야 한다. 리드가 판정의 자리와 거른 흐름의 처분을 정했다. 구현 커밋 `776e35e` · `83665ae` · `e16498b`
- 관련: [ADR-0278](0278-followed-flows-are-tops-at-or-above-the-follow-threshold-or-subscribed-less-the-excluded-and-the-keep-threshold-is-0-2.md)(보충 — 구독했지만 남길 기준 아래로 내려간 흐름을 화면에 둘지), [ADR-0287](0287-user-storyline-summaries-are-made-and-stored-by-user-with-the-users-key-and-digest-supplies-the-flow-standing.md)(정리를 만드는 자리), [ADR-0288](0288-summaries-are-made-after-a-digest-ends-only-for-changed-flows-and-extended-with-new-events.md)(처분)

## 맥락

- 관심 흐름과 남길 흐름은 조회 때 계산하는 값이다. 화면마다 계산하면 화면을 열 때마다 반응 · 노출 · 구독 이력을 읽는다.
- 정리가 없는 흐름은 제목이 없어 화면에 보일 것이 없다.
- 추적한 흐름도 싫어요가 쌓이면 거른 흐름이 된다.

## 결정

- **보이는 흐름은 정리가 있는 사용자 스토리라인이다.** 탭 · 개인 흐름 화면 · 다이제스트 항목의 제목 링크 · 관심사 히스토리의 흐름 행이 모두 정리의 저장 행만 읽는다.
- **판정은 정리 작업이 한다.** 관심 흐름이면 정리를 만들고, 관심 흐름도 남길 흐름도 아니게 되면 정리를 지운다. 화면은 판정하지 않는다.
- **추적했어도 거른 흐름은 관심 흐름이 아니어서 정리를 만들지 않는다.** 추적 중인 흐름 목록에는 남는다.
- **판정을 내지 못하면 지우지 않는다.**

## 결과

- 보이는 흐름은 길어야 다음 다이제스트까지 낡은 판정을 보인다. 해제한 흐름은 추적 중인 흐름 목록에서 바로 사라진다.
- 관심 흐름이지만 아직 정리되지 않은 흐름은 탭에 없다 — 다이제스트 항목의 흐름 추적 버튼과 공용 타임라인으로 닿는다.
- 정리를 지워도 시도 기록(호출 수 · 토큰 합)은 남는다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 화면을 열 때 관심 흐름을 판정해 정리와 맞춘다 | 탭 · 다이제스트 · 히스토리가 열릴 때마다 관심 재료를 읽는다 |
| 추적한 흐름은 거른 흐름이어도 보인다 | 싫어요를 거듭 누른 흐름의 정리에 토큰을 쓴다 |
| 정리가 없는 관심 흐름도 대표 기사 제목으로 보인다 | 탭이 공용 목록과 정리가 섞인 화면이 된다 |

# 07. 로드맵

각 마일스톤은 "완료 기준"을 만족해야 다음으로 넘어간다. 일정은 정하지 않는다.

## M0. 골격

- Gradle 멀티 모듈(또는 단일 모듈 + Modulith 패키지), Spring Boot 4, Flyway, Testcontainers 기반 테스트
- React + Vite 프로젝트, OpenAPI → TS 타입 생성 파이프라인
- Compose `dev` 프로필(Postgres, mock-oauth2-server), Spring profile `local`의 Fake 평가기·다이제스트 생성기, Dockerfile(멀티 아키텍처), GitHub Actions 테스트
- **완료 기준**: `docker compose up`으로 빈 앱이 뜨고 헬스 체크가 통과한다. Modulith 구조 검증 테스트가 CI에서 돈다.

## M1. 수집

- 소스·피드 관리 (운영자 API, 최소 화면)
- 수집 스케줄링, 조건부 GET, 파싱, 정규화, L1·L2 중복 제거
- 피드 상태 관리(`DEGRADED`, `STALE`)
- 조사한 국내 피드 형식 이상 사례를 테스트 픽스처로 만든다. 직접 작성한 합성 데이터로 만든다.
- **완료 기준**: 피드 10개 이상이 48시간 연속 수집되고, 중복률·날짜 추정 비율이 운영자 화면에 보인다.

## M2. 공유 평가

- 태그 체계 버전 관리, 질문·설명·중요도 기준 관리, 축별 임계값
- `ArticleEvaluator` + `JevArticleEvaluator`, 평가 대기열과 재시도
- 운영자 화면: 태그 분포, 기사당 태그 수, 확률 분포, 기사별 평가 결과, 요청당 토큰
- **완료 기준**: 1주일치 기사가 평가되고, 운영자가 표본 100건을 검수해 축별 임계값 `τ` 초기값을 정한다.

## M3. 사용자와 키

- OIDC 로그인(운영 기본 Google, 개발은 mock 서버), 자체 로그인(가입, 복구 코드, 봇 차단), 외부 계정 연결, 세션, CSRF
- 화면 내 알림(비밀번호 변경, 키 무효, 다이제스트 실패)
- BYOK 키 등록·검증·삭제(OpenAI, Anthropic), envelope encryption, API 키 발급 안내
- 키가 없는 사용자는 키 등록 페이지로만 이동
- 관심 설정: 구독 주제, 지역·형식 제외, 관심사 텍스트, 제외 소스, 생성 시각
- **완료 기준**: 사용자 간 데이터 격리 테스트 통과, 로그·오류 응답에 키가 남지 않음을 테스트로 확인한다. 계정 존재 노출 방지와 로그인 실패 지연이 테스트로 확인된다.

## M4. 다이제스트

- 후보 선별, 프롬프트, 구조화 출력 검증, 저장
- 일정 기반 생성과 수동 재생성(횟수 제한)
- 웹 UI: 오늘의 다이제스트, 지난 다이제스트, 원문 링크, 생성 상태와 토큰 사용량
- **완료 기준**: 테스트 사용자 몇 명이 1주일간 매일 다이제스트를 받는다. 실패율과 평균 토큰 사용량을 측정한다.

## M5. 피드백과 공개 준비

- 좋아요/싫어요, 싫어요 기사 후보 제외
- 탈퇴·데이터 삭제, 개인정보처리방침·이용약관 페이지
- 운영 배포(VPS + Tunnel), 백업과 복구 리허설
- **완료 기준**: 공개 베타 오픈.

## 이후

| 단계 | 내용 |
|---|---|
| 외부 API | Personal Access Token, `/public-api/v1` 읽기 전용(다이제스트·기사·검색), 요청 제한 |
| MCP 어댑터 | Spring AI MCP 서버 + OAuth 2.1 인가 서버. ChatGPT 등에서 다이제스트를 불러와 후속 대화 |
| 개인화 고도화 | 피드백을 프롬프트·가중치에 반영 |
| 사건 묶기 | 임베딩(pgvector) 기반 클러스터링 ([ADR-0007](adr/0007-defer-event-clustering.md)) |
| 소스 확장 | 사용자 피드 추가(상한 포함), 해외 뉴스, 본문 추출(허용 소스 한정) |
| 기본 티어 | 키가 없는 사용자용 저비용 다이제스트 |
| 메일 | 이메일 인증, 메일 기반 비밀번호 재설정, 다이제스트 알림 ([ADR-0011](adr/0011-no-email-in-v1.md)) |
| 주간 트렌드 | 주간 다이제스트, 주제별 변화 추적 |

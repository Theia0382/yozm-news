# 운영

서비스를 띄우고 운영하는 쪽의 문서다. 독자는 셀프 호스팅 운영자다. 문서 위계는 [docs/README.md §1](../README.md#1-문서-위계)에 있다.

- **담는 것**: 배포 구성 실행, 운영 설정(환경 변수) 레퍼런스, 호스팅 · 외부 서비스 연결, 비밀 값 관리, 백업 · 복구, 관측, 소스 등록 같은 운영 작업의 안내
- **담지 않는 것**: 운영 설정이 바꾸는 규칙의 정의(그 규칙을 가진 모듈의 [Spec](../specs/README.md)), 개발 · 검사 환경([development/](../development/README.md)), 판단의 이유([adr/](../adr/README.md))
